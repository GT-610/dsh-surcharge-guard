# dsh-surcharge-guard

为 DeepSeek Harness（DSH）中的服务商和模型单独设置长上下文加价阈值。插件在接近阈值时尝试压缩历史，不需要改动模型的上下文窗口。

## 使用

启用插件后，打开 **插件 → 计费保护**：

1. 用「预填 GPT 规则」「预填 Gemini 规则」等按钮导入建议值，或按服务商和模型 ID 手动添加。新增规则默认停用。
2. 查阅具体服务商的定价，核对「加价阈值」后逐条启用。预填数值不是已验证的服务商费率。
3. 保持总开关开启。表格中的「到线前触发于」以阈值减去安全余量计算，最低为 1 token。

| 目标 | 操作 |
|---|---|
| 提前压缩 | 加大「安全余量」；可能增加摘要开销 |
| 保留更多近期历史 | 调高「保留比例」，范围为 `0.01–0.9`；这是上限，缺口大时会压得更深 |
| 控制每轮的压缩次数 | 调整「摘要次数上限」，默认 `2`，设为 `0` 不发起压缩；每个步骤最多压一次 |
| 用便宜的模型写摘要 | 在该规则的「摘要模型」里选服务商和模型；选「沿用现有摘要设置」恢复默认 |
| 降低摘要的推理开销 | 选好摘要模型后，在「摘要推理等级」里选该模型提供的等级；「沿用模型默认」不覆盖 |
| 暂停保护但保留规则 | 关闭总开关 |

阈值和余量支持 `272000`、`272K`、`1.05M` 等写法。设置修改在后续步骤生效，不需要重启插件。

## 一次压缩怎么选

- **每个步骤只压一次**。一个步骤里连压两次只会把第一次写下的检查点再摘要一遍，净收益接近零，还多付一次摘要调用；剩下的缺口改为记一条警告。
- **压多深取决于缺口**。「保留比例」是近期历史的保留上限，不是固定值：记录的压力比触发线高出很多、尾巴又吃掉了可压内容时，尾部会收缩到下限，让一次压缩真正落到线下。
- **不压「摘要的摘要」**。候选范围如果只包含上一次压缩写下的检查点，或者估算净收益盖不住这次摘要本身，就不发起压缩。
- **不和别的压缩重复**。本步骤如果已经被 DSH 自带的压缩改写过表层，插件不再叠加第二次。

摘要模型只用于这条规则触发的压缩，主对话模型、手动压缩和 DSH 自带的压缩策略都保持原样。选了其他服务商时，待压缩的历史以及本次摘要请求里的提示和工具定义会发送给该服务商。

「摘要推理等级」依附于摘要模型：只有选了自定义摘要模型才会出现，改用别的模型会回到该模型的默认等级。等级列表来自实时模型目录；目录仍在加载、读取失败或未收录该模型时列表为空，此时只能沿用模型默认。已经保存、但目录里不再提供的等级仍会显示并标注，不会被悄悄改写。

运行时不支持所选等级时，插件记录警告并且不发起这次压缩：不写压缩标记，也不换成别的等级，本次尝试也不占用「摘要次数上限」，因此一个填错的等级不会拖累这一轮的后续步骤。当前步骤照常继续，仍可能越线。

## 限制

- 这是**尽力而为的保护，不是计费上限**。插件估算已提交历史和本步将接纳的消息；后续的提示更新、工具定义、附件定价、重试和服务商实际计数仍可能造成差异。
- 没有可安全压缩的历史、摘要失败，或压缩后仍超线时，插件不会阻断原请求。压缩通过当前会话的 DSH 后端运行，摘要调用也可能收费。插件的尝试上限不限制 DSH 自带压缩或后端内部重试，也不会让同一步骤压第二次。
- 自选摘要模型需要 DSH 的 Basic 压缩后端，并要有足够的上下文容量。换模型通常无法复用主模型的前缀缓存，摘要本身可能更慢或更贵。所选路线失败时，插件记录警告并继续当前步骤，不会回退到原摘要路线，这一步仍可能越线。
- 摘要推理等级只在选定的摘要模型上生效，DSH 自带的摘要设置、手动压缩和主对话都保持原样。等级由服务商解释：同一个名字在不同模型上未必是同样的思考预算。
- 调高推理等级会占用摘要的输出上限，而不是额外的余量。Basic 的 `maxTokens` 包含服务商计入的推理 token，超过上限即判定为截断、检查点作废。插件从被保护模型的策略继承这个上限，所以「小上限 + 高等级」可能把额度全用在思考上、摘要写不完：这次压缩失败、这一步不压缩、尝试次数照常消耗。这种失败会报告 `truncated at the token cap`，不会归咎于等级本身；校验也拦不住，因为等级本身是受支持的，只是剩下的额度不够写完。给摘要留出明显高于思考预算的上限即可避免，默认余量通常够用。

## 开发

```sh
pnpm install
pnpm check
```

测试覆盖 Host 决策、范围选择和真实注册入口渲染的设置页。安装版 DSH 还可单独验证压缩事务；模型摘要由本地桩提供，不发网络请求。在 Desktop 的 DSH 终端中执行：

```sh
ELECTRON_RUN_AS_NODE=1 "$DSH_NODE_EXECUTABLE" --test tests/installed-host.test.mjs
```
